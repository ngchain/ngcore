01 — proof-of-work · webassembly · post-quantum

designed by subtraction

ngchain is a proof-of-work chain built around two nouns and six verbs. Nothing is registered; any key spends directly. Contracts are WebAssembly, committed whole like a git blob. The frontier is the goal — usability is the constraint that shapes it.

02 — the whole model in one paragraph

An Address is identity, balance and namespace at once. A Contract is the code slot it opens under itself. That is the entire ontology.

Subtraction is the usability strategy. A smaller surface is easier to reason about, harder to misuse, cheaper to keep deterministic across every node. Every feature earns its place against this baseline.
03 — the ontology

Two nouns.
Six verbs.

hover a verb to read its effect. every tx is {Network,Type,Height,To,Value,Fee,Extra,Sign}.
NOUN / 01

Address

The 32-byte keccak hash of a public key. Identity, the balance holder, and a namespace — all at once.

identitybalancenamespace
NOUN / 02

Contract

A compiled WebAssembly module an address opens under its own namespace — committed whole like a git blob, frozen and executed while active.

wasmgit-blob commitsandboxed
VERB / 01

Generate

The mining reward — the only tx that mints.

VERB / 02

Transact

Pay an address; run its active contract. The call routes to the export named in the payload — main is the fallback.

VERB / 03

Commit

Replace the own contract module (a deflate snapshot). The first commit opens the slot.

VERB / 04

Activate

Validate and freeze the module, turn the VM on — runs init once.

VERB / 05

Deactivate

Turn the VM off, reopen the module for commits.

VERB / 06

Destroy

Remove the own slot entirely.

05 — the design rule

Frontier ambition, bounded by usability.

/ 01

WebAssembly, not a bespoke VM

Any language that targets wasm produces a contract, with standard tooling and a decade-hardened sandbox. The frontier choice and the usable one at once.

/ 02

Determinism is the hard constraint

Every validator must compute the same result — and the same gas — on every architecture. It is the filter every performance idea passes through.

/ 03

Exact money, native speed

Token amounts are exact U256, but the hot operations run in a native host module over 32-byte operands — removing a ~1000× ceiling without touching gas semantics.

06 — quick start

Build it.
Spend directly.

Keys stay local; only signed txs travel. A throwaway local chain is one flag away. Fork a running chain for contract debugging, anvil-style.

~/ngcore copy ⧉
# build $ go build -o ngcore ./cmd/ngcore # a throwaway local chain $ ./ngcore --zeronet --in-mem # a wallet — keys never leave the machine $ ./ngcore cli key --new --scheme secp256k1 $ ./ngcore cli send --to <bs58> --value 1.5 --fee 0.0001 # first commit deploys the contract $ ./ngcore cli commit --file contract.wasm --fee 0.0001 $ ./ngcore cli activate --fee 0.0001 $ ./ngcore cli call --contract <bs58> --entry balance_of
